# Pruebas de rendimiento con k6

## Objetivo

Organizar los scripts, escenarios y configuraciones que se utilizarán para evaluar el rendimiento de Movies Go.

Las pruebas permitirán medir tiempos de respuesta, observar errores y analizar el comportamiento de la aplicación bajo diferentes niveles de carga.

## Estructura

- `scenarios/`: scripts correspondientes a los distintos escenarios de prueba.
- `config/`: configuraciones reutilizables para ejecutar los escenarios.

## Estado actual

La estructura se encuentra en preparación. Los escenarios y la ejecución de las pruebas se incorporarán en la fase correspondiente del proyecto. En cuanto esté finalizado este documento será actualizado. 

**Herramienta prevista:** [k6](https://grafana.com/docs/k6/latest/).
